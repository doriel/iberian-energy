# The web service, and nothing else. This is the file Render installs.
#
# Short on purpose, and shorter than it was before the workbench. The dashboard
# at / is still served from app/public/data.json, which is built by
# scripts/export_public_data.py and committed, so that page needs nothing to be
# awake. pandas and pyarrow stay out: nothing at request time reads a Parquet
# file or queries a warehouse.
#
# The SDK and the Postgres driver had to come in. /workbench reaches Lakebase,
# whose credentials last sixty minutes and have to be generated per connection,
# and it calls a serving endpoint. Both need the SDK to authenticate as the
# service principal. The dashboard does not import either, and main.py loads the
# workbench routes inside a try, so a deployment missing the configuration still
# serves the page a visitor lands on.
#
#     pip install -r requirements-app.txt
#     python -m uvicorn app.main:app --reload --port 8000
#
# Upper bounds because this is the only surface that is deployed rather than
# run by hand, and a major release landing on its own during a deploy is not a
# debugging session worth having.
