# Everything that runs on a laptop or in CI: ingestion, the medallion build,
# the analysis, the agent and the tests.
#
# The web service does NOT install this file. It installs requirements-app.txt,
# which is deliberately much shorter. Keeping the two apart is the point: the
# app serves a JSON file that was built here, so it has no reason to carry a
# dataframe library or a cloud SDK into its deploy.
#
#     pip install -r requirements.txt

pandas>=2.0
# pandas reads and writes Parquet through an engine it does not depend on, so a
# fresh clone without this fails at the first read_parquet rather than at import.
pyarrow>=15.0
requests>=2.32
databricks-sdk>=0.30
# scripts/check_bundle_paths.py reads the bundle definition. It was available
# by accident as somebody else's transitive dependency, which is exactly the
# kind of thing a clean CI environment is for finding.
PyYAML>=6.0

# Tracing and experiment tracking for the agent. Skinny rather than full
# MLflow: this project needs the client and the decorator, not a model registry
# server or a UI. The floor is 3.11.1 because that is where the Unity Catalog
# trace location API arrives.
#
# The code treats it as optional and degrades to a no-op without it. Declaring
# it anyway means CI exercises the real decorator rather than only the fake one,
# so a release that breaks the shim fails a build instead of a run.
mlflow-skinny>=3.11.1

# Tests. A third file for two lines costs more attention than it saves.
pytest>=7.4
numpy>=1.26

# tests/test_app_routes.py drives the real application, so the test run needs
# what the application needs. These arrive from requirements-app.txt on the
# deploy host and are repeated here because CI's test job installs this file
# and nothing else, and a route test that quietly skips is worse than no route
# test: it reports green while the door it checks is unlatched.
fastapi>=0.115,<1.0
pydantic>=2.0,<3.0

# Starlette's TestClient needs an HTTP client, and which one depends on the
# Starlette that FastAPI pulls in. Current versions want httpx2 and say so;
# Starlette 1.0 and earlier want plain httpx. Both are listed so the suite runs
# either way, and the test module skips itself rather than erroring if neither
# import works.
httpx2>=0.1; python_version >= "3.9"
httpx>=0.27
